FAQ

A few things you might want to know before you start.

Will my audio files be uploaded?

No. WaveAtlas is a fully local tool — all parsing, waveform rendering, BPM and mood analysis happen inside your browser. No server involved, nothing uploaded. You can even go offline to verify it.

How do I “install” and “uninstall”?

No installation needed. The whole app is a single ~95 KB HTML file — download it, double-click to open in Chrome / Edge, done. To uninstall, just delete the file. No traces left.

Which audio formats are supported?

It recognizes and lists audio files with 17 extensions including MP3, WAV, FLAC, OGG, M4A, AAC, OPUS, AIFF, APE and MIDI; playable formats depend on your browser's built-in codecs (Chrome / Edge covers most common ones; WMA conversion recommended).

Why is “Choose Folder” access needed?

It's the local folder read permission provided by the browser (Chrome / Edge 86+). After granting it, the tool can list and read the folder you chose. Access is limited to that folder and read-only — the tool never modifies, moves or deletes any file.

It's free — how do I update?

The tool keeps improving. Just download the latest HTML file and overwrite the old one — zero migration cost.
