常見問題

在使用之前，你可能想知道這些。

我的音訊檔案會被上傳嗎？

不會。觀瀾是純本機工具，所有解析、波形渲染、BPM 與情緒分析都在你的瀏覽器內完成，沒有任何伺服器參與，也沒有任何資料上傳。你可以斷網使用來驗證這一點。

怎麼「安裝」和「解除安裝」？

不需要安裝。整個軟體就是一個約 95 KB 的 HTML 檔案，下載後雙擊用 Chrome / Edge 開啟即用。想解除安裝？刪除檔案即可，不留任何痕跡。

支援哪些音訊格式？

可識別並列出 MP3、WAV、FLAC、OGG、M4A、AAC、OPUS、AIFF、APE、MIDI 等 17 種副檔名的音訊檔案；實際可播放的格式取決於瀏覽器內建解碼器（Chrome / Edge 覆蓋絕大多數常見格式，WMA 建議轉檔）。

為什麼需要「選擇資料夾」授權？

這是瀏覽器（Chrome / Edge 86+）提供的本機資料夾讀取權限，授權後工具才能列出並讀取你選擇的資料夾。授權範圍僅限該資料夾，且唯讀——工具不會修改、移動或刪除任何檔案。

免費使用，以後怎麼更新？

工具會持續迭代。重新下載最新版 HTML 檔案、覆蓋舊檔即可完成升級，沒有任何遷移成本。
